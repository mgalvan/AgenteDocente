Collega Google alla webapp

Questa configurazione si esegue una volta sul server. Poi, nelle schede dei quiz, usa Collega Google e Crea modulo Google.

  1. Nel progetto Google Cloud 684501675906 abilita Google Forms API e Google Drive API.
  2. In Google Auth Platform ? Client crea una credenziale di tipo Applicazione web.
  3. Registra come URI di reindirizzamento autorizzato: https://INDIRIZZO-WEBAPP/api/google/callback. Per prove sul PC: http://localhost:8000/api/google/callback.
  4. Scarica il JSON della credenziale e conservalo sul server fuori dalla cartella pubblica. Su Cloud Run usa Secret Manager e monta il file, per esempio in /secrets/google/oauth.json.
  5. Imposta GOOGLE_OAUTH_CLIENT_FILE al percorso del JSON e GOOGLE_OAUTH_REDIRECT_URI all'URI esatto registrato nel client.
  6. Se l'app OAuth ? in test, aggiungi il tuo indirizzo tra gli Utenti di test.
  7. Riavvia il server e premi Collega Google nella scheda del quiz.

Il collegamento richiede soltanto drive.file: accesso ai file creati dal programma. Le immagini vengono condivise temporaneamente per l'importazione nel modulo, poi lo script revoca la condivisione e le cestina. Le restrizioni della scuola possono impedire questa operazione.

Su Cloud Run configura massimo 1 istanza e 100% del traffico su una revisione: questa versione conserva i collegamenti in memoria. Dopo un riavvio o un nuovo deploy occorre ricollegare Google; i moduli creati restano su Drive. La protezione dell'accesso alla webapp resta quella del tuo servizio Cloud Run.
